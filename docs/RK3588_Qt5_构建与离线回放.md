# RK3588 Qt5构建与离线回放

## 工程路径

- Ubuntu主工程：`/home/d508/projects/2025_SWIRVision_Linux`
- RK3588测试工程：`/root/projects/2025_SWIRVision_Linux`
- 板端可执行文件：`build/rk3588-debug/SWIRVision`

## 板端编译

```bash
cd /root/projects/2025_SWIRVision_Linux
bash scripts/linux/build_rk3588_native.sh debug
```

程序入口是`main.cpp`中的`main()`；qmake读取`SWIRVision.pro`生成Makefile，make再将源码编译并链接为ARM64程序。

## 离线回放复现

```bash
cd /root/projects/2025_SWIRVision_Linux
python3 scripts/linux/generate_synthetic_raw.py \
  --width 2048 --height 2048 --frames 3 \
  --output build/synthetic_2048x2048_3f.raw \
  --last-frame-output build/expected_last.raw

bash scripts/linux/run_rk3588_x11.sh debug \
  --offline build/synthetic_2048x2048_3f.raw \
  --offline-width 2048 --offline-height 2048 \
  --offline-fps 5 --offline-frames 3 \
  --offline-save build/application_last.raw
```

自动测试源码和`test_rk3588_offline.sh`已在完成阶段验收后从当前工作树精简，历史版本保存在Git提交`3331952`中。
